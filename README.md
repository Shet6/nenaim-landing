# Ненайм для репетиторов

Исходный проект лендинга на React, TypeScript, Vite и Tailwind CSS.

## Локальный запуск

```bash
pnpm install
pnpm dev
```

## Проверка перед публикацией

```bash
pnpm build
pnpm preview
```

Основная ветка `main` подключается к Vercel. Каждый push в `main` автоматически публикует новую версию сайта.
